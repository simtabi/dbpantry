# SHA-256 of every file an image build downloads by URL (design.md D-71).
#
# mdb-fetch looks a download up here by its full URL -- which carries the
# version, unlike some of the file names -- and refuses it if the digest
# differs, or if the URL is missing and the call does not say how the file is
# verified instead. A version bump in a Dockerfile therefore fails the
# build until the new digest is recorded here -- on purpose: that is the moment
# someone looks at what changed upstream.
#
# Each digest was compared against the publisher's own .sha256 file where one
# exists (s6-overlay), and recorded from the release asset otherwise.
#
