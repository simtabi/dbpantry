# Minimum versions for Go modules inside the tools we rebuild (design.md D-51, D-70).
#
# One file for every image. build-go-tool raises a module to its floor only when
# the tool actually depends on it and resolves an OLDER version; it never
# downgrades and never adds a module the tool does not use. So a new Go CVE is
# fixed by editing one line here, not by finding every Dockerfile that builds
# an affected tool. Check 69 refuses a module@version passed inline instead.
#
# Format: <module> <minimum version> <why: the advisory it closes>
